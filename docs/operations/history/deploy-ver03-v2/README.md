# Ver03-v2 Deployment and Execution Records

This directory contains historical Ver03-v2 planning, controlled-run, report, notification, OHLCV, and review records from June 2026.

They are retained as implementation evidence only.

They are not current runbooks and must not be used to infer current:

- branch or commit
- runtime repository
- deployment target
- report output path
- notification behavior
- operator procedure

Use current orchestration controls and an explicit task for any deployment or runtime work.
