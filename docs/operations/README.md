# Operations Documentation

## Active directories

- `ai-orchestration/`: current AI entrypoints, overall plan, accepted state, workflow, and controls
- `strategy/`: current Product/Macro research and supporting design references
- `manual-preview/`: current local manual-review runbook

## Historical directories

- `history/`: completed deployment and operator records
- `ai-orchestration/history/`: superseded plans, old routing documents, and task-specific records
- `strategy/archive/`: superseded strategy plans

Historical directories are not default read paths and never override current source, tests, accepted contracts, or canonical plans.

New AI contexts start from:

1. `AGENTS.md`
2. `docs/operations/ai-orchestration/START_HERE.md`
