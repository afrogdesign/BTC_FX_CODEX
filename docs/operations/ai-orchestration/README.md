# AI Orchestration

## Start here

Use `START_HERE.md` for every new AI context.

## Canonical current files

- `INITIAL_PROMPT.md`: ChatGPT Project prompt source
- `START_HERE.md`: shortest role-aware router
- `MASTER_PLAN.md`: overall Product/Macro/AI relationship and version gates
- `CURRENT_STATE.md`: accepted repository and product state
- `NEXT_ACTION.md`: exactly one current task
- `AI_WORKFLOW.md`: ChatGPT/Codex execution and review process
- `CONTROL.md`: stable safety, git, runtime, and validation rules
- `PRODUCT_IMPLEMENTATION_ROUTE.md`: current Product/P route
- `AI_OPERATIONS_STATUS.md`: conclusion of the A-route experiment
- `MILESTONES.md`: major accepted checkpoints
- `DECISIONS.md`: durable decisions and supersession records
- `REPO_MAP.md`: active and historical directory map

`TASK_LEDGER.md` is a historical Work ID lookup, not a startup document.

## History

Completed task records, superseded plans, pre-optimization copies, compatibility pointers, and old runtime records are stored under `history/`.

Do not use history files to infer current state, current branch, current paths, or the next task.

## Removed duplicate routes

The former `handoffs/` directory and compatibility entry files were retired after their useful rules were absorbed into the canonical files above.
