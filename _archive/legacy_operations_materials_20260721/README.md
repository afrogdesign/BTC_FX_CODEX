# Legacy Operations Materials Archive

archived_at: 2026-07-21
status: historical / non-canonical

This directory contains the former contents of `運用資料` that were used by older Ver02 and Ver03 operating models.

Archived categories include:

- former ChatGPT project settings
- former `NEXT_TASK.md`
- old development roadmaps and phase plans
- work logs
- progress boards and progress history
- old operating procedures and command notes
- reference material
- Ver02 explanatory report collections

## Why archived

The material mixed several generations of plans, runtime procedures, generated evidence, and AI routing rules. It could cause new AI contexts to select obsolete branches, phases, or next tasks.

## Current replacements

- startup: `AGENTS.md` and `docs/operations/ai-orchestration/START_HERE.md`
- overall plan: `docs/operations/ai-orchestration/MASTER_PLAN.md`
- state: `docs/operations/ai-orchestration/CURRENT_STATE.md`
- next action: `docs/operations/ai-orchestration/NEXT_ACTION.md`
- workflow: `docs/operations/ai-orchestration/AI_WORKFLOW.md`
- controls: `docs/operations/ai-orchestration/CONTROL.md`

## Use rule

Read a file here only for a specifically identified historical decision, implementation lineage, or incident. Never use this archive to determine the current task or current operating policy.

The tracked historical report snapshot from the former output area is preserved under `reports_snapshot/`. New generated reports use `local/reports/` and remain uncommitted.
